ו-`text` **אינו הפרמטר האחרון** — אחריו בא `&app_absent=0`. זה מכוון:
סיומת שמוצמדת לסוף הקישור בזמן הפתיחה (למשל `#no_universal_link`) נבלעת
בערך של הפרמטר האחרון, וכשהיא נבלעת ב-`app_absent` ההודעה נשארת נקייה.
**קישור חדש — להשאיר פרמטר אחרי `text`.**
